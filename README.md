# Client Finder — 2GIS

MVP для поиска клиентов в Казахстане: 2ГИС → фильтрация → автоматическая проверка сайтов → персональная генерация сообщений → CSV.

## Запуск
1. Нужен Node.js 18+.
2. В папке проекта: `npm install`
3. Скопировать `.env.example` в `.env`.
4. В `.env` указать `DGIS_API_KEY` из 2GIS Platform Manager.
5. Необязательно: `OPENAI_API_KEY` для AI-генерации. Без него используется встроенный генератор.
6. `npm run dev`
7. Открыть http://localhost:5173

API-ключи хранятся только на backend и не попадают во frontend.

Не делай массовую автоматическую рассылку: приложение готовит лиды и черновики сообщений; отправку лучше выполнять вручную и соблюдать правила платформ и требования к коммуникациям/персональным данным.
