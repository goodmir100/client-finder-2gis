# 🚀 Client Finder 2GIS — Парсер Лидов и Генератор Коммерческих Предложений

**Client Finder** — это мощный инструмент для фрилансеров, UI/UX дизайнеров и фронтенд-разработчиков, который автоматизирует поиск локальных клиентов в Алматы через API 2ГИС, анализирует их веб-присутствие и использует искусственный интеллект для мгновенного создания персонализированных холодных B2B-сообщений.

Проект построен на современном стеке **Vue 3 + Tailwind CSS** на фронтенде и **Node.js (Express)** на бэкенде. Интегрирован полностью бесплатный, автономный шлюз ИИ (Llama-3 / Mistral), не требующий платных API-ключей.

---

## 🌟 Основные Возможности

* 🔍 **Умный поиск по 2ГИС:** Нахождение организаций по конкретным рубрикам (Салоны красоты, Кафе, Автосервисы и др.) в Алматы.
* 🛡️ **Фильтрация лидов:** Автоматическое скрытие компаний, у которых уже есть сайт, позволяя сфокусироваться только на «горячих» потенциальных клиентах.
* 🌐 **Проверка доступности сайтов:** Прямой пинг указанных ссылок (сервер проверяет HTTP-статус, доступность и редиректы).
* 🤖 **Бесплатная ИИ-генерация писем:** Автоматическое составление уникальных сопроводительных писем под специфику конкретного бизнеса без использования платного OpenAI API.
* 📊 **Экспорт в CSV:** Возможность выгрузить всю базу собранных лидов вместе с контактами, оценками приоритета и сгенерированными ИИ письмами в Excel-таблицу.

---

## 🛠️ Технологический Стек

* **Frontend:** Vue 3 (Composition API, `<script setup>`), Vite, Tailwind CSS v4.
* **Backend:** Node.js, Express, CORS, Dotenv.
* **AI Integration:** Бесплатный текстовый шлюз Pollinations AI (модели Llama-3 / Mistral).
* **Data Provider:** 2GIS Сatalog API (3.0).

## 🚀 Быстрый Запуск

### 1. Клонирование репозитория и установка зависимостей
```bash
# Клонируй проект
git clone https://github.com

# Перейди в папку проекта
cd client-finder-2gis

# Установи все необходимые npm-пакеты
npm install
```

### 2. Настройка переменных окружения (`.env`)
Создай файл `.env` в корневом каталоге проекта и укажи свой ключ API 2ГИС Справочника:
```env
DGIS_API_KEY=твой_реальный_ключ_catalog_api_2gis
```
> *Примечание: Если ключ не указан или указан неверно, приложение автоматически перейдет в защищенный демонстрационный режим со встроенной базой компаний Алматы, чтобы вы могли протестировать интерфейс и работу ИИ.*

### 3. Раздельный запуск проекта (Рекомендуемый)
Для максимальной стабильности локальной работы на Windows рекомендуется запускать сервер и клиент в двух отдельных вкладках терминала VS Code.

* **В первом терминале (Бэкенд-сервер):**
  ```bash
  node server/index.js
  ```
  *Вы увидите подтверждение:* `Client Finder запущен на http://localhost:3001`

* **Во втором терминале (Фронтенд-клиент):**
  ```bash
  npm run client
  ```
  *Откроется локальная ссылка сборщика:* `http://localhost:5173/`

## 📐 Логика Оценки Приоритета (Lead Scoring)

Приложение автоматически рассчитывает ценность лида по 100-балльной шкале на основе факторов уязвимости его веб-присутствия:
* **Отсутствие сайта:** +35 баллов (Максимальный приоритет)
* **Сайт недоступен (ошибка 404/500):** +20 баллов
* **Есть рабочий телефон:** +10 баллов
* **Высокий рейтинг бизнеса (>= 4.5 ⭐):** +10 баллов (Клиент готов платить за развитие)
* **Много отзывов (>= 20):** +10 баллов
